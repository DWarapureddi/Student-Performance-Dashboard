# Student Performance & Attendance Dashboard

## Project Overview

This Power BI dashboard analyzes student academic performance and attendance data using interactive visuals and filters.

## Features

- Student performance analysis
- Final marks analysis
- Attendance analysis
- Department-wise performance analysis
- Gender-wise analysis
- Department filtering
- Gender filtering
- Interactive dashboard slicers
- Visual analysis of student performance

## Tools Used

- Power BI
- Microsoft Excel
- GitHub

## Dashboard

The dashboard provides interactive visuals to analyze student marks and attendance across different departments and genders.

![Student Performance & Attendance Dashboard](screenshot.png)

## Dataset

The dataset contains student information including:

- Student ID
- Student Name
- Gender
- Age
- Department
- Attendance
- Assignment Score
- Mid Marks
- Final Marks
