# Student Performance & Attendance Dashboard

## Project Overview
This Power BI dashboard analyzes student academic performance and attendance data.

## Features
- Student performance analysis
- Final marks analysis
- Attendance analysis
- Department-wise performance
- Gender-wise filtering
- Department filtering
- Interactive dashboard slicers

## Tools Used
- Power BI
- Microsoft Excel
- GitHub

## Dashboard
The dashboard provides interactive visuals to analyze student marks and attendance across different departments and genders.

## Dataset
The dataset contains student information including:
- Student ID
- Student Name
- Gender
- Age
- Department
- Attendance
- Assignment Score
- Mid Marks
- Final Marks
